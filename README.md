# Средневековая стратегия

Браузерная мультиплеерная пошаговая стратегия. Клиент — чистый JavaScript + canvas
(`public/`), сервер — Node.js + Express + ws (`server/`). Игровая логика
(`public/js/state.js`, `logic.js`, `units.js`, `terrain.js`, `maps.js`, `checksum.js`,
`build.js`) — общая для клиента и сервера.

## Локальный запуск (npm run dev)

Локальный живой контур без VPS: свой порт и свои сохранения.

1. Один раз установите зависимости сервера: `cd server && npm install`.
2. Из корня репозитория запустите: `npm run dev`.
3. Откройте в браузере: <http://localhost:8090>.

Подробности:

- Скрипт `dev` задаёт `PORT=8090` и запускает `server/index.js` — тонкую точку входа,
  которая делегирует в `server/server.js`; порт читается из `process.env.PORT`
  (по умолчанию 8080).
- Сохранения локального контура лежат в `saves/` рядом с запущенной копией сервера
  (`server/../saves`) и не пересекаются с сохранениями тестового и прод-контуров.
- Клиент подключается по WebSocket к тому же адресу, откуда открыта страница
  (`location.host`), внешних обращений к VPS нет.
- Остановка: Ctrl+C в терминале, где запущен `npm run dev`.

## Проверки

- `npm run check` — синтаксис всех модулей клиента и сервера, симметрия карт,
  состав нейтралей, детерминизм контрольной суммы.
